Pivotick Graph Transformer

Turn security data into a graph, without touching Pivotick

Format converters that turn third-party graph/data formats — MISP today, STIX/VirusTotal Graph/ AIL-framework planned — into the exact { nodes, edges } shape the Pivotick graph visualization library expects. No npm package, no build step for the library itself — it's added as a git submodule and imported by relative path, straight into whatever Pivotick app already renders it.
